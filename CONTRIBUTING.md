# Contributing

This repository is published as a starting point for people who want to build
on the KEBA P40 integration and API experiments.

Pull requests are not accepted or reviewed. Please fork the repository and
continue development in your own project. You are welcome to reuse, modify and
redistribute the code under the terms of the MIT License.

Issues may be used to share reproducible findings or compatibility notes, but
there is no guaranteed support or response time.
